I design and build software in Queensland, Australia. Most of it is data tooling. The rest is games, puzzles and tools for learning, some of them built with my son.

What I do

Work

At DataCrafter Software Labs I build DataCrafter, a data engineering platform: workflows, data models and reports over many data sources at once.

For fun

Games and learning tools: a territory game, two chess trainers, a Rubik's Cube solver, a PDF editor and a small C compiler.

Open source

Everything except DataCrafter is open source under the MIT licence. Fork it, build it, change it. The Windows installers are signed in my name.
